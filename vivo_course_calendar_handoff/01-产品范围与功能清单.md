# 产品范围与功能清单

## 一、产品定位

这不是一个重新实现完整日历的应用。第一阶段只解决一个核心问题：把不同来源的 Excel 课程可靠地接入手机系统日历，并支持后续更新与撤销。

## 二、P0：首个可用版本

| 模块 | 功能 | 验收标准 |
|---|---|---|
| 文件导入 | 支持 `.xls`、`.xlsx` | 可通过系统文件选择器读取两份样表 |
| 格式识别 | 自动识别校内、兼职课表 | 正常样表无需用户选择模板 |
| 校内解析 | 解析课程、教师、教室、日期、大节 | 有课单元格均能形成待导入事件 |
| 兼职解析 | 解析学生、课节、状态、精确时间 | “待上课”记录正确形成事件 |
| 作息配置 | 春季、夏季两套五大节时间 | 用户可查看并修改每个大节 |
| 导入预览 | 导入前展示事件和异常 | 可编辑或排除单条事件 |
| 日历写入 | 创建独立系统日历 | vivo 日历中可显示事件 |
| 提醒 | 课前提醒 | 支持关闭、10、20、30 分钟 |
| 去重 | 防止重复事件 | 同一文件重复导入不新增副本 |
| 差异更新 | 对比新增、修改、取消 | 执行前展示变更摘要 |
| 撤销 | 撤销某次导入 | 不影响用户其他日历事件 |
| 本地隐私 | 本地解析和存储 | 默认不上传课表和学生数据 |

## 三、P1：体验增强

- 今日课表与下一节课倒计时。
- 校内课程与兼职课程颜色区分。
- 校内课程和兼职课程冲突检测。
- 桌面小组件。
- ICS 导入与导出。
- 导入报告：成功、跳过、更新、异常数量。
- 学期归档和历史课程浏览。
- 用户可新增自定义解析模板或字段映射。

## 四、P2：vivo 专属适配

- OriginOS 通知和锁屏显示优化。
- vivo 后台策略、电量优化提示。
- 调研原子组件能力。
- 预留原子岛/实时任务适配层。

原子岛不能成为首版依赖。没有正式公开且可申请的第三方接口前，只实现标准 Android 日历与通知能力，不调用隐藏 API。

## 五、明确不做

- 首版不做账号系统。
- 首版不做云同步。
- 首版不做社交、选课评价或校园论坛。
- 首版不做完整日历替代品。
- 首版不上传或分析学生隐私数据。
- 不通过非公开系统接口强制“上岛”。
