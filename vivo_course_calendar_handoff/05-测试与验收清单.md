# 测试与验收清单

## 一、解析测试

- [ ] 正确识别老式二进制 `.xls` 校内课表。
- [ ] 正确识别扩展名与真实格式不一致的兼职课表。
- [ ] 正确处理空工作表。
- [ ] 正确处理合并单元格和多行文本。
- [ ] 正确清理 `\r`、多余空行和首尾空格。
- [ ] 正确解析多教师课程。
- [ ] 正确解析不同长度的教室名称。
- [ ] 正确解析兼职课精确开始和结束时间。
- [ ] 未知课节状态进入人工确认，不静默丢弃。
- [ ] 损坏文件不会导致应用崩溃。

## 二、时间测试

- [ ] 夏季五个大节映射正确。
- [ ] 春季下午时间未配置时阻止直接导入对应事件。
- [ ] 一大节生成一个 100 分钟日历事件。
- [ ] 兼职课不受学校作息配置影响。
- [ ] 跨月份和跨年份日期正确。
- [ ] 时区变化后事件行为符合产品设定。

## 三、日历测试

- [ ] 首次创建独立校内课程日历。
- [ ] 首次创建独立兼职课程日历。
- [ ] 重复导入不创建重复事件。
- [ ] 修改课程时间后更新原事件。
- [ ] 撤销导入只删除对应批次事件。
- [ ] 用户手动修改系统日历事件后的冲突策略明确。
- [ ] 日历权限拒绝、永久拒绝和重新授权流程正确。
- [ ] 单条写入失败不影响其他事件。

## 四、业务测试

- [ ] “待上课”兼职课默认导入。
- [ ] “已结课”默认不写入未来日历。
- [ ] 校内和兼职课时间冲突时明确提示。
- [ ] 新课表中消失的旧事件不会被静默删除。
- [ ] 导入结果显示新增、更新、跳过、异常数量。

## 五、vivo / OriginOS 真机测试

- [ ] vivo 日历正确显示标题、地点和提醒。
- [ ] 锁屏状态能收到提醒。
- [ ] 通知权限关闭时有明确提示。
- [ ] 应用被清理后台后系统日历提醒仍有效。
- [ ] 深色模式下预览页面可读。
- [ ] 不同字体缩放比例下关键按钮不被截断。
- [ ] Android 8 至目标版本的权限逻辑正确。

## 六、隐私与安全

- [ ] 无网络状态可以完成全部核心功能。
- [ ] 日志不包含完整学员 ID、班级 ID 等标识。
- [ ] 崩溃报告默认不附带原始 Excel 内容。
- [ ] 删除导入批次后，本地映射同步清理。
- [ ] 应用卸载不会破坏用户其他日历。

## 七、发布验收门槛

- [ ] 两份提供的样表均可完成解析预览。
- [ ] 校内未来课程的日期、大节、课程名和教室准确。
- [ ] 兼职“待上课”记录的起止时间准确。
- [ ] 同一文件连续导入三次仍只有一份事件。
- [ ] 更新和撤销操作无误删。
- [ ] vivo 真机完成一次完整导入流程。
- [ ] 原子岛不可用时不影响其他功能。
