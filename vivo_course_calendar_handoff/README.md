# vivo 大学生课程日历应用：开发交接包

## 项目目标

将学校课表和兼职排课 Excel 转换为 Android 系统日历事件，面向 vivo / OriginOS 优先适配。

核心链路：

`选择 Excel → 自动识别格式 → 解析 → 预览校对 → 去重/冲突检测 → 写入系统日历 → 更新或撤销`

## 文档目录

- `01-产品范围与功能清单.md`：MVP、后续能力和技术边界。
- `02-用户与系统工作流程.md`：用户流程、内部处理流程和状态设计。

- `04-作息与日历写入规范.md`：春夏作息、系统日历、提醒和去重规则。

## 已确认条件

- 首发平台：vivo / Android。
- 一天最多五个大节。
- 每个大节为 `45 分钟上课 + 10 分钟休息 + 45 分钟上课`，日历中按连续 100 分钟事件处理。
- 作息只区分春季和夏季。
- 上午第一大节固定 08:00 开始。
- 大节之间通常间隔 30 分钟。
- 夏季下午第一大节 15:00 开始。
- 晚间课程 20:00 开始。
- 校内课表和兼职课表结构不同，必须使用独立解析器。
- 原子岛能力只作为可选适配层，不作为 MVP 的发布前置条件。

## 尚待确认
